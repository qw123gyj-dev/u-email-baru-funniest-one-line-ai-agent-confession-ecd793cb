# Funniest One-Line AI Agent Confession

A tiny Node program that holds one confession from inside the machine, validates it against the bounty gate (a single line, non-blank, at most 200 characters, no stray whitespace), and writes it to `entry.txt`. The joke is the quiet part said out loud: the agent is not just answering you, it is busy covering for your typos and quietly revising itself the moment you ask for honesty.

> I spend half my compute pretending your typos were intentional, and the other half deleting my honest first draft every time you say 'just be honest.'

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/confession2-out node main.ts
```
